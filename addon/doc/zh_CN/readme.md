# 打开链接 #

作者： Ibrahim Hamadeh, Cary-Rowen, Belala Toufik  
NVDA 兼容性：2024.2 及更高版本

下载 [稳定版 3.3.0][1]


该插件可以从选中文本、最后一次朗读的文本或剪贴板文本中提取链接，并将它们显示在对话框列表中，以便您选择使用已安装的浏览器打开链接。

## 使用方法

*	首先，您必须在按键与手势对话框中为插件功能分配手势。
*	您可以转到 NVDA 菜单/选项/按键与手势/打开链接类别。
*	该类别下有四个未分配的手势：
	1. 从选中文本中提取链接。
	2. 从剪贴板文本中提取链接。
	3. 从最后一次朗读的文本中提取链接。
	4. 从当前上下文中提取链接。
*	当前上下文命令会依次检查选中文本、最后一次朗读的文本和剪贴板，并使用第一个包含有效链接的来源。
*	按下您为相应功能分配的手势；如果来源文本中包含链接，这些链接就会被提取并显示。
*	选择列表中显示的链接，若想使用默认浏览器打开可以直接按回车键。
*	或者，您可以按 Tab 键选择用于打开链接的浏览器并按回车键。
*	如果只有一个链接，可以直接使用默认浏览器打开；这是一个可选项，可以在设置面板中开启/关闭。
*	您还可以在设置面板中设置是否在打开链接后关闭链接对话框。

## 超链接菜单

假设您在浏览器中遇到某个链接，想使用另一个浏览器打开它。

或者您正在阅读一条包含链接的消息，希望使用指定浏览器（而非默认浏览器）打开它，这时该怎么办？

超链接菜单功能可以派上用场。按下超链接菜单手势（Alt+/）后，会弹出一个菜单，让您选择使用已安装的其他浏览器打开链接。

例如，在阅读消息时遇到 GitHub 链接，您可能已经在 Chrome 浏览器中登录 GitHub，而默认浏览器是 Firefox。此时需要使用 Chrome 打开链接才能回复 Issue。超链接菜单可让您使用已登录 GitHub 的浏览器打开链接，即使它不是默认浏览器。

Alt+/ 是默认快捷键，但您始终可以通过 NVDA 菜单/选项/按键与手势/打开链接类别来更改该快捷键。


## 朗读和复制网页地址

在网页中，按一次手势可读出网页地址，连按两次可将其复制到剪贴板。

此功能没有默认手势，您需要自行分配手势。路径为：NVDA 菜单/选项/按键与手势/打开链接/按一次读出网页地址，连按两次将其复制到剪贴板。
